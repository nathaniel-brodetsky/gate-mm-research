# Hypothesis registry

One file per hypothesis: `H-NNN-short-name.md`, based on `TEMPLATE.md`.
The file is committed before the experiment runs. Results are appended; the original statement is never edited.

From H-004 on, decision rules follow [D-002](../docs/decisions/D-002-testing-standard.md): the median
over pairs at a level calibrated in the synthetic lab; per-pair results are descriptive.
